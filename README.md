# Starter

Minimal starter template for **Nuxt 5**, **Nuxt UI**, and **Vite+** on **Cloudflare Workers**.

Powered by [Qarpeo](https://qarpeo.com).

## Quick Start

### 1. Install dependencies

```bash
vp i
```

### 2. Start Development Server

```bash
vpr dev
```

### 3. Build

```bash
vpr build
```
